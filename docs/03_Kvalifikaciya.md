# 3 Тестирование по программам повышения квалификации

В соответствии с приказом 98/д от 06.04.2026 «О проведении обучения по программам повышения квалификации студентов выпускных курсов университета» в период прохождения производственной (преддипломной) практики пройдено обучение по программам повышения квалификации «Профессиональная этика и этикет» и «Деловой русский язык». Результаты прохождения итогового тестирования приведены на рисунках 15–16.

Прохождение данных программ позволило закрепить знания, необходимые для профессиональной коммуникации, грамотного оформления деловой документации, а также соблюдения норм речевой культуры с применением принципов профессиональной этики в образовательной и будущей профессиональной деятельности.
